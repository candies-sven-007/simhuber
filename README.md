# SIMHuber Pro (Android)

融合 **VoHive2 0.3.2** 与 **SIMHub 23.5** 核心能力的 Android 客户端（Kotlin + Jetpack Compose）。

## 核心特性
- **真实运营商数据库**：内置 1,343 条 VoWiFi IKEv2/ePDG 运营商预设与 3,082 条 MCC/MNC 记录、APN 与 GSMA RSP 根证书。
- **暗夜渐变卡面**：直观展示多卡槽（USB CCID / eSTKme Air / OpenStick VoHive2 中继）状态、余额与到期时间。
- **VoHive2 路由与节点**：支持 Tailscale / LAN 节点探测、MCC 分流、SOCKS5 上游代理、Cloudflare TURN 与 TUN 开关。
- **eSIM LPAd & 拨号短信**：支持 eSIM Profile 管理、原始 APDU 控制台、VoWiFi 拨号键盘与保号账本。
